Gallerist ist ein Programm, das der Verantwortliche allein auf seinem eigenen Laptop nutzt. Es hat keine weiteren Nutzer.

2. Nutzung der YouTube API Services

Gallerist verwendet die YouTube API Services, um Videos des Betreibers auf seinen eigenen YouTube-Kanal hochzuladen. Wer das Programm nutzt, stimmt den YouTube-Nutzungsbedingungen zu. Für die Verarbeitung durch Google gilt die Datenschutzerklärung von Google.

3. Welche Daten das Programm verarbeitet

Zugangsdaten für YouTube

Bei der einmaligen Anmeldung mit dem Google-Konto des Betreibers erhält das Programm einen Zugangsschlüssel mit dem Recht, Videos hochzuladen (youtube.upload). Dieser Schlüssel und die Zugangsdaten des Google-Cloud-Projekts liegen ausschließlich im Schlüsselbund des Betriebssystems auf dem Laptop des Betreibers.

Videos und Texte

Beim Hochladen sendet das Programm die Videodatei, den Titel und die Beschreibung an YouTube. Von YouTube erhält es die Kennung des hochgeladenen Videos und dessen Sichtbarkeit zurück und speichert beides lokal, um den Stand anzuzeigen.

Was das Programm nicht tut

  • Es ruft keine Daten anderer YouTube-Nutzer ab und speichert keine.
  • Es liest keine Kanaldaten, Kommentare oder Statistiken über die YouTube API Services.
  • Es verwendet keine Cookies, keine Werbung und keine Analysewerkzeuge.
  • Es gibt keine Daten an Dritte weiter. Empfänger sind nur die Plattformen, auf denen der Betreiber selbst veröffentlicht.

4. Speicherort und Dauer

Alle Daten liegen lokal auf dem Laptop des Betreibers. Es gibt keinen Server des Programms. Die Zugangsdaten bleiben gespeichert, bis der Betreiber die Verbindung in den Einstellungen des Programms trennt; dabei werden sie gelöscht.

5. Zugriff widerrufen

Der Zugriff des Programms auf das Google-Konto lässt sich jederzeit auf zwei Wegen beenden:

  • im Programm unter „Einstellungen“ mit „Verbindung trennen“
  • in den Sicherheitseinstellungen von Google unter security.google.com/settings/security/permissions

2. Use of YouTube API Services

Gallerist uses YouTube API Services to upload the owner's videos to the owner's own YouTube channel. By using the application, the user agrees to be bound by the YouTube Terms of Service. Processing by Google is subject to the Google Privacy Policy.

3. What data the application processes

YouTube credentials

During the one-time sign-in with the owner's Google account, the application receives an authorization token limited to uploading videos (youtube.upload). This token and the Google Cloud project credentials are stored only in the operating system keychain on the owner's laptop.

Videos and text

When uploading, the application sends the video file, its title and its description to YouTube. It receives the ID of the uploaded video and its privacy status in return and stores both locally to show the upload status.

What the application does not do

  • It does not access or store data of other YouTube users.
  • It does not read channel data, comments or statistics through YouTube API Services.
  • It does not use cookies, advertising or analytics tools.
  • It does not share data with third parties. The only recipients are the platforms the owner publishes to.

4. Storage and retention

All data is stored locally on the owner's laptop. The application has no server. Credentials remain stored until the owner disconnects the account in the application's settings, which deletes them.

5. Revoking access

The application's access to the Google account can be revoked at any time in two ways:

  • in the application under “Einstellungen” (Settings) with “Verbindung trennen” (Disconnect)
  • on the Google security settings page at security.google.com/settings/security/permissions

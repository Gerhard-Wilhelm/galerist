Was Galerist ist

Galerist ist ein Programm, das auf dem Laptop des Kanalbetreibers läuft. Er plant damit seine Videos, schneidet sie und veröffentlicht sie auf seinen eigenen Konten bei Instagram und YouTube.

Das Programm hat genau einen Nutzer: den Betreiber selbst. Es wird nicht verkauft, nicht vermietet und nicht anderen Personen angeboten. Es gibt keinen Online-Dienst und keinen Server; alles läuft lokal.

Was das Programm macht

  • Wochenplan, Drehliste und Ideensammlung für Kurzvideos
  • Schnitt eigener Aufnahmen im Hochformat mit Texteinblendungen und Untertiteln
  • Veröffentlichung der fertigen Videos auf dem eigenen Instagram-Konto
  • Hochladen derselben Videos auf den eigenen YouTube-Kanal

Nutzung der YouTube API Services

Galerist verwendet die YouTube API Services ausschließlich, um Videos des Betreibers auf seinen eigenen YouTube-Kanal hochzuladen. Dafür nutzt es eine einzige Funktion der YouTube Data API (videos.insert) mit dem Zugriffsrecht youtube.upload.

Das Programm liest keine Daten anderer YouTube-Nutzer, zeigt keine YouTube-Inhalte an und lädt keine Videos herunter.

Wer das Programm nutzt, stimmt den YouTube-Nutzungsbedingungen zu. Es gilt außerdem die Datenschutzerklärung von Google. Einzelheiten stehen in der Datenschutzerklärung dieses Programms.

What Galerist is

Galerist is an application that runs on the channel owner's laptop. It is used to plan and edit the channel's videos and to publish them to the channel's own accounts on Instagram and YouTube.

The application has exactly one user: the owner. It is not sold, licensed or offered to anyone else. There is no online service and no server; everything runs locally.

What the application does

  • Weekly plan, shot list and idea backlog for short videos
  • Editing of the owner's own footage in vertical format with text overlays and subtitles
  • Publishing the finished videos to the owner's own Instagram account
  • Uploading the same videos to the owner's own YouTube channel

Use of YouTube API Services

Galerist uses YouTube API Services for one purpose only: uploading the owner's videos to the owner's own YouTube channel. It calls a single method of the YouTube Data API (videos.insert) with the youtube.upload scope.

The application does not read data of other YouTube users, does not display YouTube content and does not download videos.

By using the application, the user agrees to be bound by the YouTube Terms of Service. The Google Privacy Policy applies as well. Details are in this application's Privacy Policy.
